# Диагностика ультразвукового расходомера — вариант 20

Учебный проект классифицирует состояние четырёхканального ультразвукового расходомера по диагностическим параметрам. В анализ включены счётчики **C** и **D**: исходные файлы взяты из приложенного архива и находятся в `data/Flowmeters/`.

## Запуск

Нужны Python 3.10+ и NumPy:

```powershell
python -m pip install -r requirements.txt
python analysis.py
```

Скрипт выполняет повторную стратифицированную кросс-валидацию отдельно для C и D, затем проверяет перенос C→D и D→C. Он записывает метрики, матрицы ошибок, сводку признаков и графики в `results/` и `figures/`.

## Состав проекта

- `analysis.py` — загрузка и проверка данных, стандартизация внутри каждой обучающей части, мультиномиальная логистическая регрессия с L2-регуляризацией, оценка качества и построение SVG-графиков.
- `data/Flowmeters/Meter C`, `data/Flowmeters/Meter D` — предоставленные исходные данные.
- `data/README.md` — источник, лицензия и схема 43 признаков.
- `report.md` — результаты и выводы обычным языком.
- `results/` — метрики, матрицы ошибок, оценки важности групп признаков и параметры запуска.
- `figures/` — обязательные графики.

Для интерпретации важности признаки переставляются группами. Это устойчивее одиночных оценок, когда параметры четырёх акустических путей коррелируют между собой, но остаётся ориентиром для данной модели, а не причинным объяснением неисправности.

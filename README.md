# Диагностика ультразвукового расходомера — вариант 20

Учебный проект классифицирует состояние четырёхканального ультразвукового расходомера по диагностическим параметрам. В анализ включены счётчики **C** и **D**: исходные файлы взяты из приложенного архива и находятся в `data/Flowmeters/`.

## Запуск

Нужны Python 3.10+ и NumPy:

```powershell
python -m pip install -r requirements.txt
python analysis.py
python model_comparison.py
```

Первый скрипт проверяет логистическую модель, признаки и перенос. Второй сравнивает четыре классификатора с многоклассовым большинством и бинарными постоянными ориентирами «всегда без неисправности» и «всегда неисправность». Оба выполняют стратифицированную кросс-валидацию отдельно для C и D; второй также проверяет перенос C→D и D→C.

## Состав проекта

- `analysis.py` — логистическая модель, групповая важность признаков и исходные графики.
- `model_comparison.py` — сравнение логистической регрессии, k-NN, Gaussian Naive Bayes, случайного леса и базовых прогнозов.
- `data/Flowmeters/Meter C`, `data/Flowmeters/Meter D` — предоставленные исходные данные.
- `data/README.md` — источник, лицензия и схема 43 признаков.
- `report.md` — результаты и выводы обычным языком.
- `results/` — метрики CV и переноса, ошибки по классам, матрицы и важность групп признаков.
- `figures/` — предметные графики и сравнение моделей.

Для интерпретации важности признаки переставляются группами. Это устойчивее одиночных оценок, когда параметры четырёх акустических путей коррелируют между собой, но остаётся ориентиром для данной модели, а не причинным объяснением неисправности.

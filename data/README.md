# Данные и атрибуция

В каталоге `Flowmeters/` лежат файлы счётчиков C и D из ZIP-архива, предоставленного для задания. Каждый файл содержит строки без заголовка: **первые 43 значения — входные признаки, последнее значение — класс состояния**. В анализе используются только C и D, так как у них совпадает набор признаков и есть все четыре класса. Счётчики A и B из исходного архива не включены в задачу этого варианта.

## Порядок признаков

Нумерация соответствует исходным столбцам UCI:

| Столбцы | Группа признаков |
|---|---|
| 1 | Профиль-фактор |
| 2 | Симметрия |
| 3 | Поперечный поток |
| 4–7 | Скорость потока по четырём путям |
| 8–11 | Скорость звука по четырём путям |
| 12–19 | Мощность сигнала на концах четырёх путей |
| 20–27 | Качество сигнала на концах четырёх путей |
| 28–35 | Усиление на концах четырёх путей |
| 36–43 | Время пролёта на концах четырёх путей |
| 44 | Класс состояния |

Коды целевого класса: **1** — исправен, **2** — газ в потоке, **3** — влияние установки, **4** — отложения воска/парафина. Более детальные единицы измерения и порядок пар «конец пути» в исходных файлах не указаны, поэтому они не назначаются в проекте искусственно.
